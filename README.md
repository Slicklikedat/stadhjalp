# Städhjälp 🧹

Det här är ett Kanban verktyg gjort för familjer att använda för att ha koll på hemmets sysslor.

**Live:** https://stadhjalp.vercel.app

## Funktioner

Den har funktioner som att ställa in vem/vilka som har ansvar över en speciell uppgift, när det ska göras, hur länge tills det behöver göras på nytt och rotera om det är flera som har ansvar över en uppgift.

## Tekniker
- React
- TypeScript
- Vite
- Jest

## Kom igång lokalt
Backend (port 5001):
- cd backend
- npm install
- npm run dev

Frontend (port 5173):
- cd frontend
- npm install
- npm run dev
